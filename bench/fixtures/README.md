# Benchmark fixtures

Each image is fixed, so every benchmark run sends the same bytes.
Frames are 1280 by 720 JPEGs at quality 85, the size and quality the app grabs from a video.

- `screen.jpg` is `screen.html` rendered by headless Chrome at 1280 by 800 and saved at JPEG quality 80, the app's screenshot size and quality.
  It is a made-up encyclopedia page, so no real screen content goes into the repository.
- `heart-diagram-frame.jpg` is [Diagram of the human heart (cropped)](https://commons.wikimedia.org/wiki/File:Diagram_of_the_human_heart_(cropped).svg) by Wapcaplet, CC BY-SA 3.0, padded onto a white frame.
- `starry-night-frame.jpg` is [The Starry Night](https://commons.wikimedia.org/wiki/File:Van_Gogh_-_Starry_Night_-_Google_Art_Project.jpg) by Vincent van Gogh, public domain, padded onto a black frame.
- `eiffel-tower-frame.jpg` is [Tour Eiffel Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Tour_Eiffel_Wikimedia_Commons.jpg) by Benh Lieu Song, CC BY-SA 3.0, padded onto a black frame.
